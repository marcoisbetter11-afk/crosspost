Privacy policy

Crosspost · Last updated 21 November 2026

Crosspost is a personal tool that runs only on a computer or server its owner controls. It copies the owner's own videos to the owner's own YouTube channel. It isn't offered to the public.

What it accesses

When the owner connects their YouTube account, Crosspost uses the YouTube Data API to:

  • upload videos to that channel (the youtube.upload permission), and
  • read back each uploaded video's status, such as whether it's public or private (the youtube.readonly permission).

What it stores, and where

The sign-in tokens Google issues are stored only on the owner's machine, encrypted. Videos and captions also stay on that machine. Nothing is sent anywhere except to the platforms the owner chooses to post to.

Sharing

No data is sold, shared or used for advertising. Information received from Google APIs is used only to upload the owner's videos, and follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The owner can disconnect YouTube inside Crosspost at any time, or remove its access at myaccount.google.com/permissions. Disconnecting deletes the stored tokens.

YouTube and Google

Crosspost uses YouTube API Services. Using its YouTube features means agreeing to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions can be raised through this project on GitHub.
